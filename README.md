# 📊 Superstore Sales Analytics 

## 🚀 Overview

This project showcases an end-to-end data analytics workflow using Microsoft Fabric and Power BI. The objective is to analyze retail sales data and generate actionable insights on revenue, profit, and customer behavior.

---

## 🏗️ Project Workflow

The project follows a structured analytics pipeline:

1. **Data Ingestion**

   * Raw dataset (`sales_raw.csv`) used as input

2. **Data Cleaning & Transformation**

   * Performed using PySpark in `Sales_notebook.ipynb`
   * Standardized column names and cleaned date formats

3. **Data Analysis**

   * SQL queries written in `Sales.sql`
   * Used for aggregations and business insights

4. **Data Visualization**

   * Interactive dashboard built in Power BI (`Super Store Dashboard.pbix`)

---

## 🧰 Tech Stack

* Microsoft Fabric (Lakehouse, Notebook, SQL Endpoint)
* PySpark (Data Cleaning)
* SQL (Data Analysis)
* Power BI (Visualization)
* GitHub (Project Hosting)

## 📊 Dashboard Features

* KPI Metrics:

  * Total Sales
  * Total Profit
  * Total Orders

* Analysis:

  * Revenue by Region
  * Revenue by Category & Sub-Category
  * Sales & Profit Trend over time
  * Segment-wise revenue distribution

* Filters:

  * Region
  * Ship Mode
  * Year

---

## 🔍 Key Insights

* West region generates the highest revenue
* Technology category contributes the most to overall sales
* Sales have shown consistent growth over time
* Profit growth is slower compared to revenue
* Consumer segment dominates total revenue contribution
